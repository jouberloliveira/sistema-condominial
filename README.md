# Sistema de Administração Condominial

Sistema web para gerenciamento de condomínios com Spring Boot + Tailwind CSS.

## Requisitos
- Java 21
- Maven 3.8+

## Executar
```bash
./mvnw spring-boot:run
```

Acesse: http://localhost:8080

## Módulos
- Unidades
- Moradores
- Visitantes
- Reservas de Área Comum
- Ocorrências
